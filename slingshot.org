=slingshot= 弹弓，小时候玩具。弹弓打的好，可以打鸟（现在不像以前，鸟是保
护动物，不让打了），可以打玻璃（以前玻璃也不让打）。
[[file:slingshot.png]]

本项目设计为AI智能体的弹弓。现列出用于微信公众号写文章的弹丸。

安装 =go install github.com/nanjj/slingshot/cmd/slingshot@latest=
使用
1. =slingshot mdtowx <filename.md>= - markdown文档转微信公众号html格式
   1. 把markdown文档转成适合微信公众号展示的html格式，存为
      =<filename.html>= 文件
   2. 解析 =<filename.html>= 文件中的图片文件
   3. upload 图片文件到微信公众号素材管理，调用API https://developers.weixin.qq.com/doc/subscription/api/material/permanent/api_uploadimage.html ，得到图片URL
   4. 更新图片URL到 =<filename.html>= 等待上传
2. =slingshot wxdraft= - 微信公众号草稿管理
   - 子命令，微信公众号草稿
     - =list= - 列出已有草稿, 调用API, https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_batchget.html
     - =add= -  创建草稿，用 =mdtowx= 的html输出，https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_add.html
     - =update= - 更新草稿，用 =mdtowx= 的html输出，https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_update.html
     - =remove= - 删除草稿， 调用API https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_draft_delete.html
     - =show=   - 获取草稿 ，调用API https://developers.weixin.qq.com/doc/subscription/api/draftbox/draftmanage/api_getdraft.html

说一下原因。这两个功能之前实现在 =github.com/dscli/dscli= 智能体，但发现
其实与 =dscli= 核心功能没有关系，因此打造一个弹弓项目供 =dscli= 使用。
